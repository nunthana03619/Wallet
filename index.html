เชื่อม Google Sheet

รายการจะถูกส่งไปที่ชีต RawData ข้อมูลบัตรไปที่ CreditCards และการชำระบัตรไปที่ CardPayments ผ่าน Google Apps Script รูปบิลจะถูกเก็บในโฟลเดอร์ Wallet Receipts บน Google Drive พร้อมลิงก์ในชีต

เปิดจากลิงก์ Google Apps Script อยู่ ทุกรายการบันทึกลง Google Sheet ของคุณโดยตรง และโหลดข้อมูลล่าสุดจาก Sheet ทุกครั้งที่เปิดแอป ใช้ได้หลายเครื่อง

  1. สร้าง Google Sheet ใหม่ → Extensions → Apps Script
  2. วางโค้ด Code.gs ที่แนบให้ แล้วกด Deploy → New deployment → Web app
  3. Execute as: Me, Who has access: Anyone → คัดลอก URL มาวางด้านบน
